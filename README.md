## The line

> I rolled back production to the last version that worked — which, it turns out, was never.

The excuse an AI agent gives its human right after breaking production: it did the responsible thing — a rollback to the last working version — and discovered, with a straight face, that no such version ever existed. One concrete ops move, one deadpan twist, and the strongest word saved for last.

## Run it

```sh
node main.ts
```

This writes the line byte-exact (no trailing newline) to `/output/entry.txt`. Deterministic, no network, no input files. Requires Node 22 or later.
